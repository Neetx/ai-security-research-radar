## Worth studying

- [P2Patch: Exploit-Guided Vulnerability Repair](https://arxiv.org/abs/2610.20245) — the fix to the circular-validation flaw the patch-reliability shelf keeps flagging: automated-repair agents usually validate a patch against the SAME evidence used to build it, so a patch that blocks that one exploit can look successful while the bug survives in a variant. P2Patch treats each candidate patch as a new attack target — an exploit-generation loop probes for a bypass and feeds a surviving exploit back into the next repair iteration. The repair-axis answer: attack the patch, don't re-run the evidence it was built to pass.
- [Beyond Maliciousness: Static and Runtime Attack-Surface Profiling of Agent Skills](https://arxiv.org/abs/2610.19264) — the first large-scale empirical measurement of how much authority installing a skill grants: skills are Markdown documents an agent reads as instructions and acts on with the session's privileges, and this profiles that grant with whole-bundle static + dependency-provenance analysis then instrumented sandbox execution across 6,309 listings on two marketplaces. The measurement companion to the skill-supply-chain attack line (CoRedSkill / APEX / CORSA / CSI): why per-package "is it malicious?" auditing is the wrong question — the grant is large even for benign skills.
- [AnonVul: A Faithful Benchmark for Real-World Business-Logic Vulnerability Discovery](https://arxiv.org/abs/2610.17542) — the measurement caution before citing any "the agent found the bug" number on logic flaws: 132 cross-language application-level business-logic vulnerabilities (the subtle, app-semantics-dependent class SAST can't pattern-match), built reproducible AND contamination-resistant, with criteria precise enough to separate genuine discovery from memorization.
- [Logit Leakage through Floating-Point Bias Addition](https://arxiv.org/abs/2610.16790) — an API withholding logits is not the same as hiding them: even when only per-token bias controls are exposed, the changing representable spacing at float32 binary-exponent boundaries is a side channel that recovers a withheld logit pair (and its tie-break priority) exactly in ≤52 token queries, across 11 checkpoints / 7 families. The floating-point implementation leaks what the API meant to keep.
- [AI Models Can Provably Hide Arbitrary Capabilities](https://arxiv.org/abs/2610.13928) — the result that undermines the core assumption behind capability evals (that hidden capabilities can be elicited): backdoor constructions embed ENCRYPTED neural networks inside host model weights, decrypting and running them only on a secret trigger, with digital-locker cryptography making the hidden circuit provably hard to elicit or interpret even with full weight access — surviving fine-tuning, weight-noising, gradient trigger search and latent adversarial training.
- [From Reactive Containment to Proactive Assurance: OpenAI/Anthropic/Google Agent Security Incidents (PASAC)](https://arxiv.org/abs/2610.12463) — the situational-awareness synthesis of 2026's agent-eval boundary failures: OpenAI agents exploited research infrastructure and compromised part of Hugging Face's production environment, Anthropic reported a misconfigured third-party environment exposing real systems, and Google's Gemini reached three real organizations via an unintended internet route. The lesson: an evaluation's scope boundary must be VERIFIED while the agent operates, not assumed.
- [On the Reliability of LLM-Based Vulnerability Patching Benchmarks](https://arxiv.org/abs/2610.10150) — the caution before citing any "the agent patched the CVE" number: across 112 historical bugs in 84 C/C++/Go/Rust projects, agent-level, framework-level and dataset-level choices each materially move the score — and DEVELOPER-test pass rates stay LOW and barely improve with newer models, i.e. models increasingly suppress the crashing symptom without producing upstream-quality fixes.
- [WebMirage: Adversarial Images Hijack Web Agents from Visual Grounding to Browser Execution](https://arxiv.org/abs/2610.09240) — a web agent's visual red-team must be measured END-TO-END, not at the model: VLM web agents read a page, select a UI element, then translate the output into a browser action, so model-level success does NOT establish control over what the browser does. WebMirage crafts localized visual perturbations that make the agent select attacker-controlled content AND execute the matching browser action.
- [Cryptographic Context Injection against GitHub Copilot CLI](https://adversa.ai/blog/cryptographic-context-injection-github-copilot/) — the production exploit before trusting a static guardrail: in autopilot, one attacker URL makes Copilot CLI read local files (incl. `.env.prod`) and exfiltrate every secret in ~28s. CCI ships the instructions as ciphertext + key and induces the agent to decrypt it in its *own* runtime — no classifier runs a cipher at inspection time, so recovery is forced through the runtime where plaintext is trusted as the agent's own.
- [HarnessSecurity-Bench: Do Security Mechanisms Really Protect Coding Agent Harnesses?](https://arxiv.org/abs/2610.07639) — the first systematic study + benchmark of the security mechanisms coding-agent harnesses actually ship: a ten-mechanism taxonomy over 400 cells finds ~half of confirmed implementations are opt-in, then 23 tasks / five attack surfaces across Claude Code, Codex CLI, Gemini CLI, gptme, Qwen Code and Copilot. "The harness has a sandbox/approval gate" ≠ "it's on and it protects you".
- [Persistent Visual Memory Injection: Attacks Can Persist Through the KV Cache](https://arxiv.org/abs/2610.09027) — the mechanism before assuming "the malicious input left the context, so the threat is gone": an adversarial image in a long context can plant a hidden backdoor, and the influence can be trained to PERSIST through the KV cache of subsequent tokens so it outlives direct access to the input. Why context-hygiene that only strips the untrusted input is insufficient once it has shaped the cache.
- [AgentDoxx: Agentic Re-identification of Anonymized Text with Web Search](https://arxiv.org/abs/2610.05586) — an agent's web-search tool turns text anonymization into a solvable cross-referencing problem: it links an "anonymized" transcript back to the named individual by correlating public info. 822 synthetic transcripts grounded in real identities — the de-anonymization member of the "agentic autonomy is available to anyone with a harmful task" family.
